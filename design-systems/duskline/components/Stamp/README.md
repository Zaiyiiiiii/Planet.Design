# Stamp 印章

橡皮图章式的状态标记，来自测绘局的盖章文化："没有章，就没有发生。"双线边框、打字机粗体、字距拉开。

**语气**
- `brass`（默认）= 进行中 / 待处理——旧大都会的黄铜章
- `ember` = 危险、机密、失败
- `moss` = 完成、结案、成功
- `survey` = 已登记、信息类
- `neon` = 黑市、非官方
- `signal` = 线人、身份类

颜色从不单独表意：印章里永远有文字。`moss` 与 `ember` 之间靠文字区分，不靠颜色。

**`tilt`**：旋转 −7°。每个视图最多一枚倾斜印章，通常盖在 CaseFile 上。

**你需要提供**：`children`（1–2 个词），可选 `tone`、`tilt`。
