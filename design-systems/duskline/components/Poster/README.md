# Poster 通缉令

边疆小镇贴在木柱上的通缉令：一张旧海报纸（`paper`，两个主题相同——纸就是纸），双线框、顶上一颗黄铜图钉、四角泛黄，歪着贴。大标题用 `display` 的粗板衬线，悬赏金额用锈红 `paper-rust`。

- 用于案卷发布、活动、悬赏式任务、首屏公告。每页最多一张。
- `kicker` 写一个词，字距拉开（"W A N T E D""NOTICE"）；`title` ≤ 10 个汉字或 ≤ 20 个字母。
- `reward` 写奖励或亮点；`action` 放一个主按钮。

**你需要提供**：`title`，可选 `kicker`、`subtitle`、`reward`、`rewardLabel`、`action`。
