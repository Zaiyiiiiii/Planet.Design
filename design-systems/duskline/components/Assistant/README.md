# Assistant 助手 · 卡西 Cassie

黑市里一盘被霓虹工会改装过的二手混音带，戴牛仔帽、系红色亡命徒头巾。话痨、满嘴俚语，像深夜电台 DJ，说事全用"曲目"："A 面第三首：你的平板同步完了。"

**六种情绪（`state`）**：两个卷轴是眼睛，出带口是嘴，标签会跟着情绪改字：待命"C-90 · 昏线混音"；思考时卷轴飞转、飘出音符，标签"A 面 · 第 3 首"；成功时眯眼大笑、摘帽致意，标签"HIT!"；出错时磁带从嘴里吐出来绞成一团、眉头紧皱，标签"卡带了！"（双关：卡带 = 磁带 = 卡住）；睡着时闭眼、帽子滑下来，标签"‖ PAUSE"。

**正在运行的应用**是标签粉色条上的一排小灯（最多七盏）：绿松石正常、暖黄忙碌（会闪）、苔绿完成、锈橙故障、灰色休眠。

**气泡**：一张贴着胶带的旧海报纸便条；`aside` 写成"A 面 · 第 5 首"这样的曲目号，正文是她的话。`message` 写正事，`aside` 写一句旁白，`footnote` 写脚注，`actions` 放一两个小按钮。`compact` 时只显示角色、不显示气泡，适合放在屏幕角落。

**可用性**：整个角色有一句读屏描述（谁、什么情绪、哪些应用在运行及其状态）；气泡以 `role="status"` 播报。"减少动态效果"时一切静止，但表情照样切换。

**你需要提供**：可选 `state`、`satellites: [{ id?, name, status? }]`、`level`（只有灯芯用）、`message`、`aside`、`footnote`、`actions`、`name`、`size`（默认 220）、`compact`。
