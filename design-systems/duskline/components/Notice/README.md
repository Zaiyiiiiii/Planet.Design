# Notice 署名消息

系统消息由负责这件事的角色署名。每条消息顶部一道派系色线，写着谁在说话、属于哪股势力。

**谁说什么**

| 场合 | `speaker` | 语气 |
| --- | --- | --- |
| 错误、失败 | `tally` 账房 | 只说数字：发生了什么、几次、接下来怎样 |
| 通知、新消息 | `kite` 小飞 | 快，不说完整句子 |
| 成就、完成 | `ophelia` 奥菲莉亚 | "已盖章。" |
| 空状态 | `zhaowu` 宋朝雾 | "这页还没记下任何东西。" |
| 统计、周报 | `tide` 潮先生 | 用下注的口吻 |
| 条款、公告 | `edna` 领事 | 英文官腔 |
| 新手引导 | `locket` 小锁 | 不说话；配插画时只写动作 |
| 彩蛋 | `hattie` 哈蒂修女 | 一句不该知道的话 |

**规则**
- 错误文案不道歉、不含糊：说清错在哪、怎么办。
- 同一界面同时最多一条署名消息。
- `urgent` 为真时以 `role="alert"` 播报。

**你需要提供**：`speaker`（预设键名，或 `{ name, faction, org? }`），`children`（正文），可选 `actions`、`urgent`。
