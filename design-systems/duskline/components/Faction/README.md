# Faction 派系标签

标出一段内容属于昏线城八股势力中的哪一股：徽记加名称，派系色描边。

**八股势力与令牌**
- `agency` 昏线侦探社 → `faction-agency`（钥匙孔）
- `survey` 测绘局残部 → `faction-survey`（经纬圆网）
- `union` 霓虹工会 → `faction-union`（折线灯管）
- `sunward` 向阳会 → `faction-sunward`（半个太阳）
- `choir` 回声教团 → `faction-choir`（同心圆）
- `exchange` 潮汐交易所 → `faction-exchange`（天平与潮线）
- `couriers` 航标鸟 → `faction-couriers`（羽翼箭头）
- `consulate` 母星领事馆 → `faction-consulate`（框中蓝点）

**用法**
- 派系色只用于归属标记，不做装饰或大面积底色。
- `lang="en"` 显示英文名，用于领事馆腔调的官方界面。

**你需要提供**：`faction`，可选 `lang`、`children`（覆盖名称）。
