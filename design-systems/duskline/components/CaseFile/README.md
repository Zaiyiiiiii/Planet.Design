# CaseFile 档案卡

整套系统的"卡片"：左上是马尼拉档案夹标签（写编号），顶部一道黄铜线，右下切角，下面压一层无模糊的印刷错位阴影（`shadow-print`）。

**用法**
- 用于任何"一条记录"：一个案件、一位用户、一个订单、一篇文章。
- `caseNo` 用打字机体，写真实编号（订单号、ID）。
- `meta` 放日期、地点、负责人等元数据。
- `stamp` 可放一枚倾斜的 Stamp，表示该记录的状态。
- 同一网格里的档案卡保持同宽；不要嵌套档案卡。

**你需要提供**：`title`，可选 `caseNo`、`meta`、`stamp`（一个 Stamp 节点）、`children`（正文与操作）。
