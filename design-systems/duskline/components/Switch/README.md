# Switch 开关

点按式开关，不是滑块：点一下切换，不用拖动。参照工程里的 tap-switch。昏线版：一枚切角的黄铜按键。关闭时凸起、底下压着一道描边色的厚度；按下去整块下沉、变成黄铜色，奶白色的指示灯亮起。

**一眼可辨的四重状态**：颜色、按键凸起或下沉、指示灯亮或灭、按键上的字"开 / 关"。任何一项单独失效，其余三项仍能说清状态。

**手感**
- 打开时指示灯"弹"一下，按键周围扩散一圈涟漪；关闭时按键闷声一暗。
- 手机上点按有震感：安卓用 `navigator.vibrate`，打开稍重、关闭稍轻；iOS 18 以上的 Safari 借系统原生开关触发触感。
- 系统开启"减少动态效果"时，所有动画关闭，状态照常切换。

**用法**
- 用于立刻生效的设置（"自动同步"），不用于需要提交的表单选项（那是 Checkbox）。
- 右侧标签写清打开后会发生什么，`hint` 补一句后果；点标签文字也能切换。
- 按键上的字默认是"开 / 关"，可用 `onLabel` / `offLabel` 换成更具体的状态（"同步中 / 已暂停"），两者长度尽量接近。
- 键盘：Tab 聚焦，空格或回车切换；读屏报为 switch 及其开关状态。

**你需要提供**：`label`，可选 `hint`、`checked` + `onChange(checked)`（受控）或 `defaultChecked`（自管）、`disabled`、`onLabel`、`offLabel`、`name` / `value`（随表单提交）。
