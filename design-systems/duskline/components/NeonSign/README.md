# NeonSign 霓虹招牌

地下黑市的灯管招牌：一块钉着螺丝的深色背板，上面是弯成字的灯管——英文用 `neon` 字族（Monoton，灯管字），中文回退到庆科黄油体。默认竖挂，`horizontal` 横挂。

- `tone`：`neon` 绿松石（默认）· `sign` 招牌粉（当铺、黑市）· `signal` 氩气蓝（维修、服务）· `brass` 暖黄灯泡（老酒馆、老字号）。
- 2–4 个字最好；`sub` 写一行小字。
- `flicker` 让灯管偶尔接触不良；每屏最多一块会闪的，"减少动态效果"时不闪。
- 夜城里灯是亮的；晨雾主题里灯关着，只剩灯管的颜色。
- 只做氛围和分区入口，不承载必须读懂的信息。

**你需要提供**：`text`，可选 `sub`、`tone`、`horizontal`、`flicker`。
