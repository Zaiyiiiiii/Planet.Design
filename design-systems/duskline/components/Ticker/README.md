# Ticker 行情条

潮汐交易所的报价纸带：黄铜标签加横向滚动的打字机行情。交易所什么都能下注，包括开舱日。

**用法**
- 用于实时变化、值得扫一眼的数字：价格、在线设备数、同步队列、服务状态。
- 涨用 `ecto` 加 "▲ +"，跌用 `neon` 加 "▼ −"；符号与颜色一起表意，不靠色相。
- 鼠标悬停暂停；系统开启"减少动态效果"时不滚动，改为可横向滚动的静止列表。
- 一页最多一条，放在 TopBar 下方或页面底部。

**你需要提供**：`items: [{ sym, name?, price, delta }]`（`delta` 为百分比数值），可选 `label`、`ariaLabel`。
