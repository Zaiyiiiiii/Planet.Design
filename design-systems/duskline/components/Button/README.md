# Button 按钮

装饰艺术切角按钮，是整套系统里最常见的"切角"出现处。

**用法**
- `variant="primary"`（黄铜填充）每个视图最多一个，留给这个页面存在的理由："提交证词 File report"。
- `secondary` 是默认：描边切角，用于所有普通操作。
- `danger` 只用于不可撤销的动作，文案必须写清后果："销毁证据"，而不是"确定"。
- `ghost` 只做低优先级的退出路径。
- `size`: `sm` | `md` | `lg`。`lg` 只在海报和空状态里用。

**文案**：动词在前。中英双语时中文在前、英文在后，中间一个空格，不加斜杠。按钮文字不加 "→"。

**你需要提供**：`children`（文字），可选 `icon`（一个 18px 的内联 SVG 节点），其余属性原样传给 `<button>`。

**不要**：不要改成圆角；不要在一行里放两个 primary；不要用 danger 表达"重要"。
