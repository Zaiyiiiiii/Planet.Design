昏线 Duskline 是 PLANET 三套设计系统中晨昏线的一套，属于昏线城：一座边疆小镇长成的旧大都会。三层时间叠在一起——拓荒年代的西部（通缉令、马鞍皮、绿松石、尘土里的夕阳），八十年代的纽约式繁华（剧院跑马灯、地铁圆标、粗板衬线海报），以及高架桥下地下黑市的霓虹灯管。它的姊妹是白昼面的 [日冕 Corona](https://claude.ai/artifact/TrWjabazmsXGbnGbBZpLkx)（亮、圆、玻璃）和夜面的 [深井 Deepwell](https://claude.ai/artifact/6gXx5T7Huuq4RDWKrkzQyo)（暗、硬、钢板与警示黄），三者共用同一套角色、派系和组件接口。先读 [PLANET 宇宙设定集](https://claude.ai/code/artifact/8d4d8b3a-1dda-4007-994a-1ff802b2ebde)，再用这里的令牌和组件。

## 世界，一段话

PLANET 是一颗被潮汐锁定的殖民星：一面永昼，一面永夜，人住在两者之间的晨昏线上，那座城叫昏线城。四十年前的"大熄灯"让全城档案在七分十二秒里消失，从此八股势力都在争夺那晚的真相，而普通人学会了"养卫星"——把自己的记录存在手边的旧机器里。界面里的每个角色、颜色和措辞都来自这里。

## 内容与语气

- 写得像一个累了但没放弃的人在雨夜记笔记：短句，冷幽默，不说教，不用感叹号和表情符号。
- 中英双语：中文在前、英文在后，中间一个空格，不加斜杠——"提交证词 File report"。中文是街头语言；英文是官方和母星领事馆的语言，条款、公告类文字可以只用英文官腔。
- 动词开头的按钮："翻开案卷"，不写"确定"。按钮文字不加 "→"。
- 错误不道歉、不含糊，说清错在哪、怎么办。
- 系统消息由角色署名，用 `Notice` 组件：错误归账房 `tally`，通知归小飞 `kite`，完成归奥菲莉亚 `ophelia`，空状态归宋朝雾 `zhaowu`，统计归潮先生 `tide`，条款归领事 `edna`，引导归小锁 `locket`，彩蛋归哈蒂修女 `hattie`。
- 比喻只取材于这颗星上有的东西：盐、灯管、潮汐、印章、电车、月亮、卫星。不借用任何现成作品的名词。

好："账房：请求未送达。误差 1 次。已重新排队，预计 3 秒。"
不好："哎呀，出错了！请稍后再试～"

## 两个主题：夜城与晨雾

两个主题都是晨昏线的天色。`night`（夜城）是默认，也是品牌的本来面目：砖红色的夜 `void`，页面底部压着一道玫瑰到威士忌色的地平线余晖，覆着极淡的斜向雨丝。`daylight`（晨雾）是被晒褪色的土坯和旧海报纸，适合长时间阅读；晨雾里霓虹是关着的，所有 `glow-*` 光晕都归零。

- 页面底 `void`；面板、侧栏 `smog`；输入框、档案卡正文、弹层 `raised`。
- 正文 `ink`，次要 `ink-muted`，三种表面上两个主题都 ≥5.6:1。
- 发丝线 `line`，控件边框 `line-strong`（≥3.3:1）。
- 键盘焦点：2px 实线 `focus-ring`（氩气蓝），偏移 3px。
- 通缉令用的 `paper` / `paper-ink` / `paper-rust` 两个主题相同：纸就是纸。

**和深井怎么区分**：深井是炭黑与硫磺黄，没有天、没有雨、没有光，一切是钢板。昏线有夕阳、有雨、有灯管在亮；它的暗是砖红的，主色是绿松石，旧东西是皮革与黄铜色，看上去是"老"的，而不是"重"的。

## 颜色的分工

- `neon` 绿松石霓虹：西南荒漠的绿松石，也是灯管的颜色。昏线城唯一的操作色——主按钮、选中项、开关、当前页、进度。它上面的文字用 `on-neon`；夜城里主按钮悬停会亮起 `glow-neon`。
- `signal` 氩气蓝：链接、信息、焦点环、仪表。
- `brass` 威士忌皮革：旧大都会与边疆小镇留下的东西——档案卡、印章、标志、跑马灯框、马鞍皮色。不做操作色。
- `sign` 招牌粉：只用在"地下"的东西上——黑市招牌、黑市印章、价签上的价钱。
- `moss` 暮光苔：成功、上涨、在线、结案。`ember` 锈橙：危险、下跌、机密、毁坏。状态永远配文字或 ▲▼。
- `survey` 测绘墨蓝只用于"已登记"类印章与测绘局的派系标记。派系色 `faction-*` 只用于归属标记。
- 带 `-soft` 的令牌只做同色文字的底。

## 字体

- `display`：Alfa Slab One，通缉令和 80 年代海报上的粗板衬线。只有一个字重，只用于 24px 以上的标题；中文回退到庆科黄油体。
- `neon`：Monoton，弯成字的灯管。只用于霓虹招牌和跑马灯上的英文。
- `label`：Big Shoulders，地铁站牌式的压缩无衬线。按钮、标签页、导航、表单标签；中文回退到黑体。
- `serif`：Newsreader，正文。`mono`：Courier Prime，打字机——编号、时间、数值、行情、印章。
- 不要把 `neon` 字族用在正文或按钮上；它是招牌，不是文字。

## 形状：切角，不是圆角

- 方舟测绘时代的装饰艺术建筑留下了八角切角，这是整套系统唯一的招牌。所有矩形都是直角（`radius-0`），需要柔化时用切角：`cut-sm` 标签页、小按钮、输入框；`cut-md` 按钮、档案卡、消息；`cut-lg` 海报。
- 圆形只属于"天体"：头像、行星标志、仪表盘，用 `radius-ring`。
- 阴影只有一种：`shadow-print`，无模糊的印刷错位，用 `filter: drop-shadow()` 施加，让它跟着切角走。不用柔和的灰色投影，不用渐变。

## 间距与布局

- 8 步间距 `space-1`（4px）到 `space-8`（64px）。卡片内距 `space-4`，卡片之间 `space-5`，区块之间 `space-6` 或 `space-7`。
- 内容左对齐。只有海报和号外标题可以用超大字号撑满一行。
- 动效克制：只有行情条会自己动，而且会尊重"减少动态效果"。其余动效只回应用户的操作。

## 标志与图标

- 标志是"钥匙孔行星"：行星是小锁，钥匙孔是那晚的秘密，光环是绕着它转的无数卫星——每个人手边的那份副本。夜面用 `planet-mark-brass` / `planet-lockup-brass`，档案日用 `-ink` 版本。在 React 里直接用 `Planet.Mark`，它随 CSS `color` 着色。
- 图标是 24px 描边图标，描边 1.75，方头、斜接转角，贴合切角语言。它们用 `currentColor`，请内联使用；放进 `<img>` 会显示成黑色。
- 八股势力的 16px 徽记内置在 `Planet.Emblem` 与 `Faction` 组件中。

## 组件一览

`Button` 切角按钮 · `TextField` 证词栏 · `Tabs` 档案夹标签 · `Stamp` 印章 · `CaseFile` 档案卡 · `Headline` 号外标题 · `Ticker` 行情条 · `OrbitGauge` 轨道仪表 · `Poster` 海报 · `TopBar` 顶栏 · `Faction` 派系标签 · `Notice` 署名消息。组件在 `components/bundle.js` 中挂在 `window.Planet` 上，需要页面先载入 React 18。

## 角色与图标

- 昏线城的群像有自己的头像（`Avatar`）：平涂 2D 的小型半身像，派系色作底，八角切角框，与按钮、档案卡的切角一致。署名消息会自动带上说话者的头像，这就是"谁在说话"在界面上的样子。
- 图标（`Icon`）是三套系统共用的 14 个图形，昏线版的线条是1.75 描边、方头端点、斜接转角——和切角一样硬朗。图标跟随文字颜色，只有图标的按钮必须带 `title`。

## 通用组件

三套系统都有同一组基础组件，接口完全相同，只是长相不同：`Button`、`TextField`、`Tabs`、`Switch` 开关、`Checkbox` 复选框、`Progress` 进度条、`DataTable` 表格、`Dialog` 对话框、`EmptyState` 空状态、`Select` 下拉选择、`Sidebar` 侧边栏、`Pagination` 分页、`Tooltip` 提示气泡、`TagInput` 标签输入、`Menu` 菜单、`List` 列表、`TopBar` 顶栏、`Faction` 派系标签、`Notice` 署名消息、`Avatar` 角色头像、`Icon` 图标。在此之上，每个国度各有自己的特色组件。换系统只需换样式表和命名空间。

## 昏线特色

除了档案卡、号外、行情条这些旧大都会的遗物，昏线还有几样只属于晨昏线的东西：

- `Poster` 通缉令：旧海报纸、双线框、黄铜图钉、锈红悬赏金额。
- `Marquee` 跑马灯招牌：一圈交替明灭的灯泡，中间是灯管字。
- `NeonSign` 霓虹招牌：钉着螺丝的背板上的灯管字，绿松石、招牌粉、氩气蓝、暖黄四种灯色。
- `RouteBadge` 环线站牌：80 年代地铁式的线路圆标，七条线七种颜色。
- `Stall` 黑市价签：歪贴的纸签、两条胶带、被划掉的原价、一行砍价备注。

## 动态标志与助手

这个国度的动态标志是 **PLANET · 昏线标志**（`Logo`）：钥匙孔小月亮——也就是全系列的吉祥物小锁——四周绕着会闪的跑马灯泡与暮光苔萤火。思考时钥匙孔亮起绿松石霓虹。中央是 PLANET，每颗卫星是一个正在运行的应用。这个国度的助手是 **卡西 Cassie**（`Assistant`）：黑市里一盘被霓虹工会改装过的二手混音带，戴牛仔帽、系红色亡命徒头巾。
