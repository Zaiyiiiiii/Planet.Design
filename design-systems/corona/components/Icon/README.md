# Icon 图标

14 个基础图标，三套系统共用同一组图形，只换线条风格。日冕版：1.75 描边、圆头端点、圆角转角——和胶囊一样柔和。

`search` 搜索 · `folder` 文件夹 · `satellite` 卫星/设备节点 · `key` 密钥 · `eye` 查看 · `check` 完成 · `close` 关闭 · `plus` 新建 · `upload` 上传 · `download` 下载 · `alert` 警示 · `sync` 同步 · `lock` 锁定 · `sliders` 设置

**用法**
- 图标用 `currentColor`，跟随文字颜色；不要给图标单独上派系色。
- 默认 20px；按钮里 18px；空状态插画旁最大 32px。
- 只有图标、没有文字的按钮必须传 `title`，作为读屏标签。
- `satellite` 是 PLANET 自己的图标：一台接入的设备、一颗卫星。

**你需要提供**：`name`，可选 `size`、`title`。
