# Assistant 助手 · 薇尔 Veil

向阳会穹顶花园里养的观赏水母，被改造成了助理。透明、优雅、轻声细语，带着一点从没见过黑夜的天真；口头禅是"别担心，阳光会处理的"。

**六种情绪（`state`）**：她的情绪写在体内的光和触须上：待命时缓缓漂浮、触须轻摆；倾听时侧身靠近；思考时一根触须卷到"下巴"、身边冒小气泡；成功时体内的光变亮、触须快速摆动；出错时整只泛粉、触须直直垂下；睡着时几乎透明、触须收短。

**正在运行的应用**是她触须末端托着的光珠（最多六颗）：白色正常、金色忙碌（会明暗呼吸）、绿色完成、红色故障、灰色休眠。

**气泡**：一个浓玻璃气泡，圆角，靠近她的一角收尖。腔调：完整的句子，轻柔，偶尔天真得有点好笑。`message` 写正事，`aside` 写一句旁白，`footnote` 写脚注，`actions` 放一两个小按钮。`compact` 时只显示角色、不显示气泡，适合放在屏幕角落。

**可用性**：整个角色有一句读屏描述（谁、什么情绪、哪些应用在运行及其状态）；气泡以 `role="status"` 播报。"减少动态效果"时一切静止，但表情照样切换。

**你需要提供**：可选 `state`、`satellites: [{ id?, name, status? }]`、`level`（只有灯芯用）、`message`、`aside`、`footnote`、`actions`、`name`、`size`（默认 220）、`compact`。
