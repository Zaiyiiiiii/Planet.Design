# Avatar 角色头像

昏线城群像的头像：每个角色一幅小型半身像，有肤色、发型、服装和表情；底色是所属势力的派系色。全部平涂 2D：靠剪影、配色和道具认人，不画光影。外框是一枚黄铜画框里的圆形肖像——像挂在图书馆墙上的小像。

**角色与标志性特征**
- `locket` 小锁：带钥匙孔陨坑的小月亮，外加一道轨道。
- `eli` 伊莱·范：软呢帽、竖起的衣领。
- `zhaowu` 宋朝雾：齐耳短发、怀里的打字机。
- `ophelia` 奥菲莉亚·墨：发髻、圆眼镜、胸前一枚印章。
- `marge` 玛格·奥瑞：推到额头的护目镜、斜挎的工具带。
- `tally` 账房：方脑袋、天线、胸前的算珠。
- `tide` 潮先生：高礼帽压到眼睛，只露出一只戴戒指的手。
- `hattie` 哈蒂修女：头巾里的一张脸，耳边是老式耳机。
- `kite` 小飞：飞行帽、护目镜、帽侧的小翼、迎风的围巾。
- `august` 奥古斯特·白：油头、墨镜、白西装的翻领。
- `edna` 艾德娜·凯恩：大檐帽、帽徽、肩章。

**用法**
- 头像代表"谁在说话"：署名消息（Notice）会自动带上说话者的头像。不要把头像当装饰贴在无关内容旁。
- 尺寸：消息里 32px，列表 48px，角色介绍 96px 起——细节在 96px 以上才完整。
- 未署名者没有头像，永远不会有。
- 每个角色的性格、往事与表情集见世界设定集的"角色设定"一页；画新表情或立绘时以那里的"视觉要点"为准。

**你需要提供**：`who`，可选 `size`（像素，默认 48）。
