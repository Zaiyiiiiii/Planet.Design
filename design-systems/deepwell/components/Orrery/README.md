# Orrery 卫星仪

深井国钟表匠做的太阳系仪：中央是行星（铜色），三道黄铜轨道上转着你的卫星——每一台接入 PLANET 的设备。外圈一道 5° 一格的刻度。在轨的设备是铜绿实心，静默的是空心；右侧是编号对照表。

- 用于"我的设备一览"、同步拓扑、节点在线概况。最多 9 颗；更多请用 List 或 DataTable。
- 位置按编号固定排布（黄金角），同一组设备每次画出来都一样。
- `note` 覆盖默认的"在轨 / 静默"，写更具体的状态（"同步中""对星季"）。

**你需要提供**：`nodes: [{ name, online?, note? }]`，可选 `label`。
