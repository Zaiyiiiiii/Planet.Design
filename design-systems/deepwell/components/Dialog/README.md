# Dialog 对话框

深井版：一块铭牌式的弹层，顶条是语气色（默认琥珀，危险操作时信号灯红），四角螺丝。

- 只用于必须先回答才能继续的问题：确认删除、确认离开。普通提示用 Notice。
- 标题是问题本身（"移除这颗卫星？"），正文说清后果，按钮写动作（"移除"），不写"确定 / 取消"之外的含糊词。
- `tone="danger"` 用于不可撤销的操作，读屏报为 alertdialog。
- 打开时焦点进入弹层，Esc 或点击遮罩关闭，关闭后焦点回到原处。
- `inline` 只用于文档和预览，让弹层原地显示。

**你需要提供**：`open`、`title`，可选 `children`、`actions`、`onClose`、`tone`、`inline`。
