# SkyPort 星空舷窗

一扇钉着八颗螺栓的铸铁舷窗，窗外是全星唯一真正的夜空：星点、一条淡淡的星座连线，以及用虚线圈标出的母星。深井国是唯一看得见星星、也最适合和母星通讯的地方。

- 用于和"远方"有关的状态：同步、备份到远端、与母星或其他节点的连接、下一次对准的时间。
- `title` 用铭牌字（"对星季 · 第 41 天"），`sub` 用读数字体写数值，`note` 一两句说明。
- 星空由 `seed` 决定，同一个 seed 永远画出同一片天。
- `showHome={false}` 时不标母星——比如不在对星季的时候。

**你需要提供**：可选 `title`、`sub`、`note`、`seed`、`showHome`、`homeX`、`homeY`、`ariaLabel`。
