# Assistant 助手 · 灯芯 Wick

长夜沙龙图书馆里的一盏黄铜夜读灯，火苗就是脸，玻璃灯罩上架着一副圆眼镜。博学、温和、节俭，爱引诗，爱加脚注，总惦记着"省着点灯油"。

**六种情绪（`state`）**：情绪写在火苗上：待命时安静地跳；倾听时火苗朝你倾过来；思考时左右摇摆、冒一缕烟；成功时窜高一截、迸出火星；出错时缩成一小簇红蓝色、噼啪作响；睡着时只剩一点蓝色余烬，眼镜摘下来放在灯座旁。火苗变小时，脸会落到眼镜下面——像从镜片底下偷看。

**正在运行的应用**是绕着灯飞的飞蛾（最多六只）：象牙白正常、琥珀忙碌（扑得更快）、霜蓝完成、红色故障（翅膀烧着了，发抖）、灰色休眠（停在灯座上，翅膀收起）。**灯座上的油窗是资源余量**（`level`，0–100）：存储、电量、配额都可以用它表示，低于 20 时油变成信号灯红。

**气泡**：一块细铭牌条的便笺，正文下方一道细线隔出脚注。`message` 写正事，`aside` 写一句旁白，`footnote` 写脚注，`actions` 放一两个小按钮。`compact` 时只显示角色、不显示气泡，适合放在屏幕角落。

**可用性**：整个角色有一句读屏描述（谁、什么情绪、哪些应用在运行及其状态）；气泡以 `role="status"` 播报。"减少动态效果"时一切静止，但表情照样切换。

**你需要提供**：可选 `state`、`satellites: [{ id?, name, status? }]`、`level`（只有灯芯用）、`message`、`aside`、`footnote`、`actions`、`name`、`size`（默认 220）、`compact`。
