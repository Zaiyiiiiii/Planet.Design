# Logo 动态标志

PLANET · 深井标志：这个国度的 PLANET 动态标志。一只袖珍星盘：黄铜表圈、48 格刻度、星盘网架、一根铜色游丝和一只镜片眼。卫星是黄铜小行星，像秒针一样一格一格地走。

标志会随主题（国度）一起更换，但含义不变：**中央是 PLANET，四周每一颗卫星是一个正在运行的应用**。卫星的小表情说明那个应用的状态——`ok` 正常、`busy` 忙碌、`done` 完成、`error` 故障、`sleep` 休眠；标志本身的 `state` 说明整个平台的情绪——待命、倾听、思考、成功、出错、睡着。超过七颗卫星时，多出来的收进"+n"。

- 放在顶栏左侧、启动页、"关于"页。顶栏里用 48–64px，启动页 160px 以上。
- 小于 48px 时卫星看不清，改用静态的钥匙孔行星标志（Logos 资源）。
- 卫星可点击（`onSatelliteClick`），跳转到对应的应用。
- 读屏会说出"什么情绪、几个应用在运行"；"减少动态效果"时静止，状态照常切换。

**你需要提供**：可选 `state`、`satellites: [{ id?, name, status?, onClick? }]`、`size`、`onSatelliteClick`。
