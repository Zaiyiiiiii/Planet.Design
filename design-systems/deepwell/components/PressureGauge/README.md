# PressureGauge 压力表

深井国锅炉房里的老式压力表：黄铜表圈、象牙色表盘、黑色指针、铜色轴帽，红线以上是一段信号灯红的危险区，表面压着一道玻璃反光。能用一百年的东西，绝不换新。

- 用于有"安全上限"的读数：压力、负载、温度、队列积压、磁盘占用。
- `value` 是 0–100 的指针位置；`reading` 是显示的实际读数；`max` 是表盘上的最大刻度；`redline`（默认 80）以上指针会进入红区，读数变红，读屏会说"超过红线"。
- 一排最多三只。

**你需要提供**：`value`，可选 `reading`、`readoutUnit`、`unit`、`max`、`redline`、`label`。
